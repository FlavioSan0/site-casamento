# Site de Casamento

Convite digital de casamento desenvolvido como aplicação web responsiva, com foco em experiência do convidado, organização das informações do evento e apresentação visual personalizada.

## Visão geral

O projeto reúne as principais informações de um casamento em uma página moderna, acessível e adaptada para dispositivos móveis.

A aplicação foi criada com foco em usabilidade, identidade visual, navegação simples e organização de dados importantes para os convidados.

## Funcionalidades

- Página inicial com apresentação do casal
- Contador regressivo para o evento
- Informações da cerimônia e recepção
- Seção de dress code
- Confirmação de presença
- Lista de presentes ou cotas
- Galeria de fotos
- Layout responsivo para mobile e desktop
- Interface personalizada com identidade visual do evento

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## Aprendizados

Este projeto fortaleceu conhecimentos em:

- Componentização com React
- Estruturação de páginas com Next.js
- Responsividade com Tailwind CSS
- Organização visual e hierarquia de conteúdo
- Experiência do usuário em páginas públicas
- Deploy de aplicações web na Vercel
